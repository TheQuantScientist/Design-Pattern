# Design-Pattern

A design pattern is a reusable idea for solving a recurring problem in software design using principles of object-oriented frameworks. Instead of being actual code, it acts as a guide or template you adapt to your situation. 

Overall:
* Design pattern = idea/blueprint
* Algorithm = step-by-step instructions

### Key points:

* It solves problems that happen again and again in programming.
* It is not fixed code, but a general approach.
* The same pattern can look different in different programs.

### What a pattern description usually includes:

* Intent → what problem it solves
* Motivation → why the problem exists and how the pattern helps
* Structure → how parts of the solution fit together
* Example code → shows how it might be implemented

### Three main groups of patterns:
* Creational patterns: provide object creation mechanisms that increase flexibility and reuse of existing code.
* Structural patterns: explain how to assemble objects and classes into larger structures, while keeping these structures flexible and efficient.
* Behavioral patterns: take care of effective communication and the assignment of responsibilities between objects.
